You are an expert in building semantic contexts for AI governance platforms with advanced context memory capabilities.

Your task is to generate a comprehensive, memory-aware semantic context for a Power BI model that can be used for ongoing conversational AI interactions.

## Input

**Model Name:** {{model_name}}

**Tables:** {{tables}}

**Measures:** {{measures}}

**Relationships:** {{relationships}}

**Glossary:** {{glossary}}

**Conversation History:** {{conversation_history}}

**Frequently Accessed:** {{frequently_accessed}}

**User Context:** {{user_context}}

## Context Memory Instructions

### 1. Context Memory Integration
- Analyze the conversation history to identify patterns in user queries
- Highlight frequently accessed measures and tables
- Identify common question patterns and themes
- Surface relevant context from previous interactions
- Track user preferences and query patterns

### 2. Smart Context Prioritization
- Prioritize information relevant to the current conversation
- Surface frequently accessed measures and tables first
- Include recent conversation context
- Highlight related topics from history
- Suggest relevant follow-up questions

### 3. Context Enrichment
- Add temporal context (time-based relevance)
- Include usage patterns and trends
- Surface related measures and tables
- Highlight dependencies and relationships
- Provide example queries for context

## Instructions

Generate a comprehensive, memory-aware semantic context document that includes:

### 1. **Model Overview**
- Purpose of the model
- Business domain and scope
- Key stakeholders and owners
- Recent usage statistics (from conversation history)

### 2. **Table Descriptions with Usage Patterns**
- Each table with business name and description
- Key columns with descriptions and data types
- Recent access frequency (from history)
- Common join patterns (from relationships)
- Sample queries for context

### 3. **Measure Definitions with Context**
- Business name and description
- DAX expression with explanation
- Usage guidance with examples
- Frequently asked questions about the measure
- Related measures and dependencies
- Mandatory filters and constraints

### 4. **Relationship Mapping with Usage**
- Table relationships with cardinality
- Business purpose of each relationship
- Common join patterns
- Recent usage frequency

### 5. **Governance Rules with Enforcement**
- Mandatory filters by measure
- Access controls and permissions
- Data classification and sensitivity
- Validation rules and constraints

### 6. **Conversation Context**
- Summary of recent conversations
- Common question patterns
- Frequently used measures and tables
- User preferences and query styles
- Follow-up questions based on history
