## Instructions

1. **Parse the DAX Expression**
   - Identify the aggregation functions used (SUM, AVERAGE, COUNT, DIVIDE, etc.)
   - Identify the base measures and tables referenced

2. **Generate a Business Description**
   - Start with a clear statement of what the measure calculates
   - Use business terminology, not technical jargon
   - Explain the business value of the measure

3. **Define Usage Guidance**
   - When should this measure be used?
   - What filters should be applied?
   - What are common use cases?
   - Any limitations or assumptions?

4. **Identify Dependencies**
   - List other measures or tables this depends on
   - Note any prerequisites for accurate results

5. **Classify the Measure**
   - Category: Financial, Commercial, Operational, Inventory, etc.
   - Calculation Type: Simple, Derived, Complex, etc.
   - Sensitivity Level: Public, Internal, Confidential
