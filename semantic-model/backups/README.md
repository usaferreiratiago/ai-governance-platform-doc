# Semantic Model Backups

This directory stores versioned backups of the Power BI semantic model exported from Tabular Editor or Power BI Desktop.

## Recommended naming convention

* model-2026-08-01.bim
* model-2026-08-15-before-release.bim
* model-2026-09-01-post-go-live.bim

## Backup procedure

1. Open Tabular Editor.
2. File → Save As.
3. Save the `.bim` file into this directory.
4. Commit the backup if version-control retention is required.
